PR Babysitter

Codex handles unanswered review threads. The binary replies only in threads, resolves fixed threads, and does every git and GitHub write.

Known limits

  1. Failing CI and conflicts. Codex attempts code fixes and conflict resolutions. The run stops when a problem needs a person or the fix limit is reached.
  2. Declined and needs_human threads. They stay open, and the merge waits until a person replies or resolves them.
  3. Lost re-review request. If a run crashes after it posts replies, the request is not retried. The merge still waits on the review decision.
  4. Large PRs. More than 100 threads, comments in a thread, reviews, review requests, or checks stops the run.
  5. Queued feedback. The run handles new review feedback while the PR is queued. A push removes the PR from the queue.
