PR Babysitter

Codex handles unanswered review threads inside the purple box. The binary replies only in threads, resolves fixed threads, and does every git and GitHub write.

Known limits

  1. Failing CI and conflicts. The binary stops and names the cause. It does not try to fix them.
  2. Declined and needs_human threads. They stay open, and the merge waits until a person replies or resolves them.
  3. Lost re-review request. If a run crashes after it posts replies, the request is not retried. The merge still waits on the review decision.
  4. Large PRs. More than 100 threads, comments in a thread, reviews, or review requests stops the run.
  5. Queued feedback. New review feedback waits until the PR leaves the queue. A push would remove the PR from the queue.
