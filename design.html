Gaps to settle

  1. CI red vs. CI pending. Right now both lead to "wait 10s". A real failure would loop forever with nobody fixing it.
  2. Update PR has merge conflicts. There is no path for this yet.
  3. Merge gate. CI green alone triggers the merge, even if a re-review is still pending or a thread is still open.
  4. After Codex handles comments. Does the flow continue to step 4 in the same pass (as drawn), or restart at step 1?
  5. Tracking by comment count. Edited or deleted comments don't change the count, or change it the wrong way. Tracking comment IDs avoids this.
  6. Stopping condition. There is no limit on loops or on time spent waiting.
